## 🖼️ 04 — ABOUT THIS IMAGE REPOSITORY

This public repository is used as a **stable asset reference point** for BangTan media. Its purpose is simple: keep image URLs easy to reference without turning the main site or app into a messy collection of one-off uploads.

**You may find assets intended for:**

- **OT7 & member imagery** — member profiles, group moments and visuals.
- **Website & app media** — images used across BangTan pages and interfaces.
- **Gallery & editorial content** — media supporting memories, timelines and updates.
- **Fan-made creative assets** — edits and graphics where inclusion and sharing are permitted.

> [!IMPORTANT]
> **Publicly accessible does not mean copyright-free.** BTS photos, logos, album art, BT21 characters and other third-party materials remain the property of their respective rights holders. This repository does **not** grant permission to reuse or redistribute third-party assets.

### ✧ How to link an asset

Find the **actual file path** in this repository, then use GitHub's raw-content domain:

```text
https://raw.githubusercontent.com/MehAk-ArmAn/BangTan-imgS/BRANCH/EXACT/PATH/filename.ext
```

For example, replace `BRANCH` with the branch containing the asset (such as `main`, **only if that is the real branch**) and `EXACT/PATH/filename.ext` with its real location. Paths and capitalization must match exactly.

```md
![Describe the image](https://raw.githubusercontent.com/MehAk-ArmAn/BangTan-imgS/BRANCH/EXACT/PATH/filename.ext)
```

**Asset care checklist:** use descriptive filenames, preserve file extensions, optimize unnecessarily huge images, keep credits/source information when applicable, and avoid breaking existing URLs when renaming or moving files. Use a commit-specific URL if an image must remain completely version-pinned.
